# 🌟 Lawwale AI Web Agent

Welcome to **Lawwale**, a web‑based AI agent designed to provide **real‑time legal guidance and support**. This project demonstrates automation, AI integration, and web development skills in a clean and interactive chat interface.

🚀 **Live Site / Demo:** https://lawwalecom.netlify.app/

## 📁 Features

- Real‑time AI‑based responses to legal queries  
- Interactive chat interface with typing indicators  
- Session management for individual users  
- Clear chat functionality to reset conversations  
- Integration with **Make.com / n8n** workflows for automated processing  

## 🛠️ Technologies Used

- HTML, CSS, JavaScript (Front‑end)  
- Python (backend processing via Make.com webhook)  
- **n8n** / **Make.com** (Workflow automation)  
- REST APIs for real‑time communication  

## 💡 How It Works

1. User types a legal query in the chat interface.  
2. The message is sent to the **Make.com / n8n webhook**, where it is processed.  
3. The AI agent generates a response and displays it in the chat in **real‑time**.  
4. Session and message history are maintained for a better user experience.
